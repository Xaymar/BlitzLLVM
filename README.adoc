== What is BlitzLLVM?
BlitzLLVM is an attempt at a BlitzBasic (Blitz2D, Blitz3D, BlitzPlus) compiler using the LLVM compiler backend to enable support for many architectures and platforms. The LLVM backend enables us to take advantage of optimizations and architecture targets that LLVM already provides for other languages, and may even enable further functionality previously considered impossible.


=== Usage
[source,sh]
----
blitzcc program.bb                    # builds the program in a temporary directory and runs it
blitzcc -o program program.bb         # builds program.exe (Windows) / program (elsewhere), without running it
blitzcc -O3 --llvm-flag -march=native --llvm-flag -flto --llvm-flag -fuse-ld=lld program.bb
blitzcc -S program.bb                 # only write the generated LLVM IR (program.ll)
----
The compiler emits textual LLVM IR and hands it, together with the embedded runtime library, to `clang` (`--cc`, `$BLITZLLVM_CC`), so `clang` needs to be installed. `--llvm-flag <flag>` passes any flag to clang, `--llvm-arg <arg>` passes one to LLVM itself (`-mllvm`), `--target <triple>` cross-compiles. The result is one self-contained executable.

Not supported yet: `Type`/`Field`/`New`, `Dim` arrays, `Goto`/`Gosub`, `Data`, and 2D images (`LoadImage`, `DrawImage`).

Graphics are drawn through Vulkan 1.3 into an SDL3 window. SDL3 and SDL3_image are linked statically, including the decoders for PNG, JPEG, BMP, TGA, WebP, AVIF (dav1d) and JPEG XL (libjxl), whose licenses are installed in `licenses/`, and the Vulkan loader is loaded when the program starts, so programs remain a single executable. Set `BLITZ_HEADLESS=1` to run a program without a window or GPU.

[cols="1,3"]
|===
| 2D | `Graphics`, `SetBuffer`, `Flip`, `Cls`, `ClsColor`, `Color`, `Plot`, `Line`, `Rect`, `Oval`, `Text`, keyboard and mouse input
| 3D world | `RenderWorld`, `AmbientLight`, `CreatePivot`, `CreateCamera`, `CreateLight`, `FreeEntity`, `EntityParent`
| Transforms | `PositionEntity`, `MoveEntity`, `TranslateEntity`, `RotateEntity`, `TurnEntity`, `ScaleEntity`, `PointEntity`, `EntityX/Y/Z`, `EntityPitch/Yaw/Roll`, `EntityDistance`
| Appearance | `EntityColor`, `EntityAlpha`, `EntityFX` (fullbright, two-sided), `EntityTexture`, `HideEntity`, `ShowEntity`
| Cameras and lights | `CameraClsColor`, `CameraClsMode`, `CameraRange`, `CameraViewport`, `CameraZoom`, `LightColor`, `LightRange` (directional and point lights, 8 at a time, lit per vertex like Blitz3D)
| Meshes | `CreateCube`, `CreateSphere`, `CreateCylinder`, `CreateCone`, `CreateMesh`, `CreateSurface`, `AddVertex`, `AddTriangle`, `VertexColor`, `VertexNormal`, `VertexTexCoords`, `UpdateNormals`, `FlipMesh`, `ScaleMesh`, `PositionMesh`, `RotateMesh`
| Textures | `LoadTexture` (PNG, JPEG, BMP, TGA, WebP, AVIF, JPEG XL and more, with the alpha, masked and clamp flags), `FreeTexture`, `TextureWidth`, `TextureHeight`
|===

Not there yet for 3D: model files (`LoadMesh`, `LoadAnimMesh`), sprites, terrains, brushes, animation, collisions and picking, spot light cones, fog, `CreateTexture` and drawing to textures.

Tests: `ctest` compiles and runs (headless) every program in `tests/` and lexes `tests/test.bb` (a token-level lexer fixture rather than a program).

The function test suite is in `tests/suite`. It has a test for every function that Blitz3D and BlitzPlus provide, taken from the original sources in `extra/`: one file per part (`math.bb`, `strings.bb`, `blitz3d_meshes.bb` and so on) that stops with an error as soon as something is wrong, and `check.bb` with what they share. Tests that look at pixels end in `_pixels` and need a window and a GPU, they are skipped when headless and run for real with `-DBLITZ_TEST_GPU=ON`. Functions that are not implemented yet have a placeholder in `tests/suite/pending`, which is expected not to compile; once a function exists, write its test in the file of its part and delete the placeholder. `tools/suite_functions.py list` rewrites `tests/suite/functions.txt` from the originals and `check` (also run by `ctest`) makes sure that every implemented function has a test. `tools/suite_signatures.py` compares the arguments of every function in `builtins.inc` with the original.
