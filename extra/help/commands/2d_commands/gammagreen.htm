Hilfe

GammaGreen

Aufruf

grün = GammaGreen (index)

Parameter

index Grün-Index (0-255)


Rückgabewert

Gamma-Anteil der Farbe Grün wird zurückgeliefert.


Beschreibung

Die Funktion GammaGreen ermittelt den aktuellen Gamma-Anteil der Farbe 'grün'. Es gibt bekanntlich 256 RGB-Farbabstufungen (0-255). Einige Farbanteile können künstlich aufgehellt oder abgedunkelt werden. Dadurch lassen sich verschiedene Effekte realisieren.


Zusatzinformation

Gamma-Funktionen können nur im Vollbildmodus verwendet werden. Im Fenstermodus zeigen diese Befehle keine Wirkung.
 


Beispiel

Hier werden 256 Gamma-Werte (grün) ausgegeben:

Graphics 640, 480, 0, 1

For i=0 To 255
   Print i+": "+GammaGreen(i)
Next

WaitKey()
End
