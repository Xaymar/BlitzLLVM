Beschreibung

Der Befehl Forever (=für immer) wird zusammen mit Repeat verwendet. Forever ersetzt somit den normalen Befehl Until. Es bildet mit Repeat eine unendliche Schleife, die nicht mehr unterbrochen werden kann. Nur mit Exit kann die Schleife noch beendet werden. Mit End wird dagegen das ganze Programm beendet.

In die Schleife müssen bestimmte Bedingungen eingebaut werden, damit die Schleife unterbrochen werden kann. Sollte man das vergessen, so gibt es dann keine Möglichkeit das Programm zu beenden. Nur mit Gewalt (strg-alt-entf) kann man es noch schaffen.
 


Beispiel

Diese Programmschleife wird nur 10x ausgeführt und dann sofort beendet:

Repeat

   mal = mal + 1

   If mal = 10 Then Exit

Forever

Print "Schleifenausführungen: " +Mal
