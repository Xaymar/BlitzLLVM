Hilfe

WaitKey

Aufruf

code = WaitKey()

Parameter

-


Rückgabewert

ASCII-Code der gedrückten Taste.


Beschreibung

Diese Funktion wartet solange, bis eine Taste betätigt wird. Das ist besonders für einfache Stopps mit der Meldung: "Hit Any Key" sinnvoll. Allerdings wird das Programm auch komplett gestoppt - man kann also während dieser Zeit keine Grafiken ausgeben (benutze dafür GetKey).

WaitKey funktioniert nicht mit allen Tasten. So werden Alttasten, Shifttasten sowie Strgtasten nicht berücksichtigt!
 


Beachte, dass ein ASCII-Code nicht der Tastatur-Scancode ist. Das sind zwei verschiedene Sachen. Hier eine Liste mit den Codes:


 


Funktioniert bei BlitzPlus nicht in der Konsole!

 


Beispiel

Standardbeispiel:

PRINT "Drücke beliebige Taste"
Taste=WAITKEY()
PRINT "Betätigte Taste: " + Taste
WAITKEY()
