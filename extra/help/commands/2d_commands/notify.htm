Hilfe

Notify

Aufruf

Notify nachricht$ [,warnung]

Parameter

nachricht Text, der ausgegeben werden soll
warnung 0=Information (Standard)
1=Warnung


Rückgabewert

-


Beschreibung

Die Anweisung Notify blendet eine Nachricht ein, die nur ein OK-Button enthält. Gebe dazu einfach einen Text ein. Zeilenumbruch kann mit Chr$(13) erfolgen. Wird Warnung auf 1 gesetzt, dann erscheint ein Warnsymbol statt Infosymbol.



Mit Apptitle kann der Fenstertitel geändert werden
 


Beispiel

Eine Nachricht wird angezeigt und dann das Programm beendet:

Notify "Programm wird beendet" + Chr$(13) + Chr$(13) + "Klicke auf OK"
End
