Hilfe

ChangeDir

Aufruf

ChangeDir Pfad$

Parameter

Pfad$ String mit einem beliebigen Verzeichnispfad


Rückgabewert

-


Beschreibung

Diese Anweisung wechselt das aktuelle Verzeichnis. Sollte dieses Verzeichnis nicht existieren, so passiert gar nichts. ChangeDir funktioniert somit genau wie der alte DOS-Befehl CD. Um das aktuelle Verzeichnis zu ermitteln, sollte CurrentDir verwendet werden.

Um problemlos in das höhere Verzeichnis zu gelangen, kann man auch ".." eingeben. Sollte das aktuelle Verzeichnis bereits das Root-Verzeichnis sein (z.B. C:), so passiert gar nichts. Auch komplexere Pfadangaben wie "../../grafik" sind möglich!
 


Beispiel

Standardbeispiel:

;Dieses Beispiel überprüft, ob ein Verzeichnis existiert (Ersatz für FileType):

ChangeDir "C:\Verz"
If CurrentDir$() <> "C:\Verz" Then Text 0, 0, "Verzeichnis nicht gefunden"
