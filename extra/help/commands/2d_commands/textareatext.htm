Hilfe

TextAreaText

Aufruf

text$ = TextAreaText$ (textarea [,pos] [,länge] [,einheit])

Parameter

textarea Identität eines Textarea-Objekts
pos Startposition in Zeichen oder Zeilen
länge Länge in Zeichen oder Zeilen
einheit 1=Einheit in Zeichen (Standard)
2=Einheit in Zeilen


Rückgabewert

Es wird kompletter Text aus Textarea zurückgeliefert


Beschreibung

Die Funktion TextAreaText liefert kompletten Text aus Textarea-Objekt zurück. Zeilenumbrüche werden als Chr$(13)+Chr$(10) - Kombination gespeichert. Die neuen Parameter Pos, Länge und Einheit sind ab BlitzPlus 1.34 verfügbar.

Neuer Text kann mit AddTextAreaText eingefügt werden. SetTextAreaColor, SetTextAreaFont oder SetTextAreaTabs ändern Farbe, Schriftart oder Tabulatorabstand.



Beispiel

Dieses Beispiel erzeugt ein Fenster mit Textarea-Objekt. Der Fenstertitel wird immer auf den Text im Textarea gesetzt, welcher mit TextAreaText$() ermittelt wird:

window = CreateWindow("", 0, 20, 400, 300, 0, 7)
textarea = CreateTextArea(0, 0, 200, 200, window)

Repeat
   SetGadgetText(window, "Textfeld: " + TextAreaText$(textarea))
   If GetKey() = 27 Then End
   If WaitEvent() = $803 Then End
Forever
