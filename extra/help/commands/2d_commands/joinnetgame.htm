Hilfe

JoinNetGame

Aufruf

Wert = JoinNetGame (Name$, ServerIp$)

Parameter

Name$ Name des beizutretenden Spiels
ServerIP$ Ip des Servers


Rückgabewert

0 = Netzwerkspiel wurde nicht gestartet
1 = Netzwerkspiel erfolgreich gestartet


Beschreibung

Startet ein Netzwerkspiel direkt ohne die Netzwerk-DialogBox. Der Computer mit der angegebenen IP-Nummer ist der Host. Bei diesem Befehl muss der Name des Spiels angegeben werden.

Normalerweise wird StartNetGame für Netzwerkspiele benutzt.


Diese DialogBox wird von dem Befehl unterdrückt.


Beispiel

Standardbeispiel:

;Dieses Programm startet ein Netzwerkspiel und prüft, ob es korrekt gestartet wurde:

gamename$ = "Spiel"
serverIP$ = "0.0.0.0"
joinResults = JoinNetGame(gamename$, serverIP$)
Select joinResults
   Case 1
      Print "Netzwerkspiel erfolgreich gestartet"
   Default
      Print "Netzwerkspiel nicht gestartet"
End Select
WaitKey()
