Hilfe

UDPStreamIP

Aufruf

IP = UDPStreamIP (Stream)

Parameter

Stream Identität eines UDP-Streams (ermittelt mit CreateUDPStream)


Rückgabewert

Es wird eine Integer-IP-Adresse zurückgeliefert. Benutze DottedIP , um daraus die normale IP-Adresse zu ermitteln


Beschreibung

Mit dieser Funktion kann die IP-Adresse eines UDP-Streams ermittelt werden. Der Rückgabewert ist ein Integer - mit der Funktion DottedIP kann eine normale IP-Adresse ermittelt werden. Benutze auch UDPStreamPort, um die Port-Adresse zu ermitteln.
