Hilfe

NNP_CreateBox

Aufruf

NNP_CreateBox.TEntity( X#, Y#, Width#, Height# [, Friction#] )

Parameter

X# X - Position des Mittelpunkts
Y# Y - Position des Mittelpunkts
Width# Breite der Box
Height# Höhe der Box
Friction# Reibungsfaktor der Box (Standard=0)


Rückgabewert

Das Entity, das erstellt wurde.


Beschreibung

Dieser Befehl erstellt eine Box und liefert das erstellte Entity zurück.
Falls beim Erstellen der Box die durch NNP_CreatePhysics festgelegten Limiten überschritten wurden, bricht die Funktion ab und liefert Null zurück.

X und Y bestimmen dabei die Position des Mittelpunktes der Box und nicht die Position der linken oberen Ecke.
