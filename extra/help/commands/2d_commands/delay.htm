Hilfe

Delay

Aufruf

Delay millisekunden

Parameter

millisekunden Anzahl der Millisekunden, die das Programm warten soll


Rückgabewert

-


Beschreibung

Dieser Befehl stoppt die Programmausführung für die angegebene Anzahl von Millisekunden. Dadurch wird die Programmausführung auf jeden Fall verlangsamt. Dies kann für die Ausgabe von Meldungen benutzt werden.

In dieser Zeit kann kein Befehl ausgeführt und keine Grafik ausgegeben werden. Um eine bestimmte Programmgeschwindigkeit zu erzwingen, ist dieser Befehl ungeeignet. Auch um die CPU zu entlasten sollte dieser Befehle nicht angewendet werden, benutze besser CreateTimer.
 


Eine Sekunde entspricht 1000 Millisekunden.
 


Beispiel

Dieses Beispiel zeigt Datum, Zeit, Laufzeit und beendet dann automatisch nach 6 Sekunden:

Print "Heutiges Datum ist: " +CurrentDate$()

Print "Aktuelle Uhrzeit:" +CurrentTime$()

Print "Windows-Laufzeit in Minuten:" +MilliSecs()/60000

Delay 6000

End
