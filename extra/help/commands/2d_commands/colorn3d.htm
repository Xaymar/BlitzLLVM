Hilfe

ColorN3D

Aufruf

ColorN3D ([red] [, green] [, blue] [, alpha#])

Parameter

red Rotanteil von 0 bis 255 (Standard = 255)
green Grünanteil von 0 bis 255 (Standard = 255)
blue Blauanteil von 0 bis 255 (Standard = 255)
alpha# Alphawert von 0 bis 1 (Standard = 1)


Rückgabewert

-


Beschreibung

ColorN3D setzt die Farbe aller folgenden nativen Befehle fest. Die gesetzte Farbe gilt solange, bis sie wieder mit ColorN3D geändert wird. Dieser Befehl ist vergleichbar mit Color, jedoch gelten die gesetzten Werte bei ColorN3D ausschliesslich für native - Befehle. Ausserdem kann ein Wert für Alpha (Transparenz) angegeben werden.
