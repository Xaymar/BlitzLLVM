Hilfe

MD2AnimLength

Aufruf

zeit% = MD2AnimLength (md2%)

Parameter

md2% Identität eines MD2-Objekts


Rückgabewert

Aktuelle Animationszeit eines MD2-Objekts in msek (relativ zur aktuellen Animationssequenz).


Beschreibung

Die Funktion MD2AnimLength ermittelt die aktuelle Animationszeit eines MD2-Objekts (relativ zur aktuellen Animationssequenz). Für diese Funktion muss man nur die Identität eines MD2-Objekts angeben. Diese Funktion kann nur mit MD2-Objekten benutzt werden. Benutze für andere Objekte den Befehl AnimLength.


Beispiel

Standardbeispiel:

Graphics3D 640, 480
SetBuffer BackBuffer()
camera = CreateCamera()
light = CreateLight()
RotateEntity light, 90, 0, 0
gargoyle = LoadMD2("media/gargoyle/gargoyle.md2")
garg_tex = LoadTexture("media/gargoyle/gargoyle.bmp")
EntityTexture gargoyle, garg_tex
PositionEntity gargoyle, 0, - 45, 100
RotateEntity gargoyle, 0, 180, 0
AnimateMD2 gargoyle, start, 0.1, 32, 46

While Not KeyHit(1)
   UpdateWorld
   RenderWorld
   Text 0, 0, "MD2AnimLength: " + MD2AnimLength(gargoyle)
   Flip
Wend
End
