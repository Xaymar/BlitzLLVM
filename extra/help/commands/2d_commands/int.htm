Hilfe

Int

Aufruf

Zahl = Int (Wert)

Parameter

Wert Einen Beliebigen Wert als Integer, Float oder String


Rückgabewert

Gerundete Zahl ohne Kommastellen.


Beschreibung

Diese Funktion wandelt eine beliebige Kommazahl aus Float oder String zu einem Integerwert. Die Zahl wird dadurch immer gerundet. So wird z.B. aus der Zahl 3.14 die Zahl 3 und aus der Zahl 3.999 die Zahl 4 ermittelt.

Wird ein String angegeben, so werden nur Zeichen vor dem Kommazeichen beachtet. Aus der Zahl 3.99 wird dann 3.
 


Beispiel

Dieses Beispiel zeigt die Integer-Zahl aus 3.14 und 3.99:

Zahl1 = Int(3.14)
Zahl2 = Int(3.99)
Print Zahl1
Print Zahl2
