Hilfe

CurrentDir

Aufruf

CurrentDir$()

Parameter

-


Rückgabewert

String$ : Pfad des aktuellen Verzeichnisses (z.B. "C:\Programme\Blitz3d")


Beschreibung

Diese Funktion liefert einen String mit dem aktuellen Pfad zurück. Dabei wird der komplette Pfad mit Laufwerkbezeichnung zurückgegeben. Ist der String länger als drei Zeichen, so befindet sich kein "\"-Zeichen am Ende. Benutze CHANGEDIR, um in ein anderes Verzeichnis zu wechseln.

Ab v1.55 wird immer ein Backslash ("\") am Ende des Strings zurückgeliefert. Falls eine manuelle Prüfung eingebaut war, so sollte es zu keinen Problemen kommen.
 


Beispiel

Wechselt das Verzeichniss und zeigt das neue an:

Print CurrentDir$()
neues_verzeichnis$="C:\" ; Das Verzeichnis in das wir wechseln soll C:\ sein
ChangeDir neues_verzeichnis$
If CurrentDir$()<>neues_verzeichnis$ Then ; eine Abfrage, ob das neue Verzeichnis das Verzeichniss ist, was wir wollten
    Print "Verzeichnis nicht gefunden"
Else
    Print CurrentDir$()
EndIf
