Hilfe

JoyDown

Aufruf

gedrueckt = JoyDown( knopf [, port] )

Parameter

knopf Die Nummer des Joystickknopfs
port Die Nummer des Joysticks (ab 0)


Rückgabewert

0 - Der Knopf wird nicht gedrückt.
1 - Der Knopf wird gedrückt.


Beschreibung

Diese Funktion ermittelt, ob ein bestimmter Joystickknopf gedrückt wird.


Zusatzinformation

Bevor du diese Funktion nutzt solltest du mittels JoyType prüfen, ob überhaupt ein Joystick angeschlossen ist.
Du solltest auch immer an eine alternative Tastatur/Maus-Steuerung denken.
 


Beispiel

Standardbeispiel:

SetBuffer BackBuffer()
While Not KeyHit(1)
   Cls
   Locate 0,0
   Print "Joystickknöpfe:"
   For t = 1 To 5
      If JoyDown(t) Then Print t Else Print "-"
   Next
   Flip
Wend
