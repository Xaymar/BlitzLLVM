Hilfe

TurnKP

Aufruf

TurnKP (kp, speed#, [t_break#])

Parameter

kp Das Handle des KP
speed# Die Drehbeschleunigungskraft selbst
t_break# Drehabhängige Bremse (Standard = 1)


Rückgabewert

-


Beschreibung

Beschleunigt ein KP in seiner Drehung. Hier gilt es den Drehmoment zu beachten. Ist das Moment sehr groß gewählt, so kann eine leichte Drehung schon zu einem fast unstoppbaren Objekt führen. Daher sollten Drehmomente möglichst klein gehalten werden. Meisten reicht ein Drehmoment von 1 schon aus. Der Drehmoment wird beim erstellen eines KP angegeben (siehe dazu NewKP). Wird eine Drehgeschwindigkeit von zum Beispiel +1 erzielt, so entspricht es einer Vektorgeschwindigkeit von ebenfalls +1, wenn das selbe KP auf einem Boden entlang rollt.

''t_break'' gibt an, wie groß eine zusätzliche Bremse beim Beschleunigen berechnet werden soll. Die Bremse ist dabei aber von der bereits tatsächlichen Drehgeschwindigkeit abhängig. So kann man zum Beispiel mit einfachen Mitteln ein Fahrzeug bauen, welches nicht unendlich Beschleunigen kann, obwohl man immer weiter Kraft dazu gibt. Dieses Verhalten ergibt eine vereinfachte Form einer Leistungskurve bei einem Motor.
