Hilfe

ClientWidth

Aufruf

breite = ClientWidth (gruppe)

Parameter

gruppe Identität einer Gruppe


Rückgabewert

Breite der Gruppe


Beschreibung

Funktion ClientWidth liefert die Breite einer Gruppe zurück. Gruppe ist die Identität eines Objekt, zu dem weitere Objekte hinzugefügt werden können (z.B. Desktop, Window, Tabber oder Canvas). Andere Objekte können ungültige Werte zurückliefern!

Clientbreite ist nicht die Breite eines Objekts, sondern nutzbare Breite ohne Rand!

Wird die Identität von Desktop angegeben, dann lässt sich die Auflösung ermitteln (siehe Beispiel).

 


Beispiel

Standardbeispiel:

window = CreateWindow("Window", 0, 0, 300, 200, 0, 1)

deskw = ClientWidth(Desktop())
deskh = ClientHeight(Desktop())

winw = GadgetWidth(window)
winh = GadgetHeight(window)

cliw = ClientWidth(window)
clih = ClientHeight(window)

txt$ = "Desktop:" + Str$(deskw) + "x" + Str$(deskh)
txt$ = txt$ + Chr$(13) + Chr$(13)
txt$ = txt$ + "Window:" + Str$(winw) + "x" + Str$(winh)
txt$ = txt$ + Chr$(13) + Chr$(13)
txt$ = txt$ + "Client:" + Str$(cliw) + "x" + Str$(clih)

label = CreateLabel(txt$, 10, 10, cliw - 20, clih - 20, window)

WaitKey()
End
