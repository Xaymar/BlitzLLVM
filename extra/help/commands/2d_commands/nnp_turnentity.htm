Hilfe

NNP_TurnEntity

Aufruf

NNP_TurnEntity( Entity.TEntity, Angle#, CenterX#, CenterY# [, ConserveSpeed] )

Parameter

Entity.TEntity Entity, das gedreht werden soll
Angle# Winkel, um den gedreht werden soll
CenterX# X - Position des Punktes, um den gedreht werden soll
CenterY# Y - Position des Puntkes, um den gedreht werden soll
ConserveSpeed Ob die Geschwindigkeit unverändert bleiben soll oder nicht (True oder False, Standard=True)


Rückgabewert

-


Beschreibung

Dieser Befehl dreht ein Objekt um einen bestimmten Winkel mit dem Drehzentrum in einem frei wählbaren Punkt.
Ist ConserveSpeed auf True gesetzt, so verändert sich die Geschwindigkeit des Objekts nicht. Ist es aber auf False, so wird das Objekt zusätzlich kreisförmig beschleunigt.

Dieser Befehl ist perfekt, um Objekte zum eigenständigen Drehen zu bringen (wie zum Beispiel die Räder eines Autos). Dafür einfach den letzten Parameter auf False setzen.
