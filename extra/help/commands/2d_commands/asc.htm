Hilfe

Asc

Aufruf

code = Asc (text$)

Parameter

text ein Text, von dem nur das erste Zeichen berücksichtigt wird


Rückgabewert

numerischer ASCII-Zeichencode (0-255)


Beschreibung

Eine Funktion zur Zeichenkettenverarbeitung, die einen numerischen Wert zurückgibt. Dieser Wert ist der ASCII-Code des ersten Zeichens in einem Zeichenkettenausdruck. ASCII-Code kann nur ein Wert von 0 bis 255 sein. Der umgekehrte Befehl lautet Chr.

Beachte, dass ein ASCII-Code nicht der Tastatur-Scancode ist. Das sind zwei verschiedene Sachen.
 





Beispiel

Dieses Beispiel zeigt die Verwendung von Asc und Chr:

txt$="Dies ist ein Text"
Print "ASCII-Code des ersten Zeichens: "+Asc(txt$)

;gibt Anführungszeichen aus:
Print Chr$(34)+"Hello World"+Chr$(34)
