Hilfe

String

Aufruf

neu$ = String$ (text$, anzahl)

Parameter

text$ Text, der kopiert werden soll
anzahl Anzahl der Wiederholungen


Rückgabewert

Zeichenkette mit sich wiederholendem Text


Beschreibung

Diese Stringfunktion kann einen Text beliebig oft in einen anderen Text kopieren. Somit steht in der neuen Zeichenkette x-mal hintereinander der übergebene Text.
