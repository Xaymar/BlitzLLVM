Hilfe

UpdateProgBar

Aufruf

UpdateProgBar progbar, progress#

Parameter

progbar Identität eines Progbar-Objekts
progress# Größe des Fortschrittbalkens (0=klein bis 1=groß)


Rückgabewert

-


Beschreibung

Die Anweisung UpdateProgBar ändert einen Fortschrittsbalken, der mit CreateProgBar erstellt wurde. Dabei werden Werte 0 bis 1 akzeptiert. 0 bedeutet 0%, 0.5 bedeutet 50% und 1 bedeutet 100% (beliebige Zwischenschritte möglich).

Progbar wird meistens bei komplexen Berechnungen eingeblendet, um den Fortschritt des Prozesses zu zeigen.


Beispiel

Standardbeispiel:

;Dieses Beispiel erzeugt ein Fenster mit Progressbar. Beim Klicken auf den "Update" - Button wird der Status in der Progressbar mit UpdateProgBar erhöht:

window = CreateWindow("Fenster", 0, 20, 400, 300, 0, 3)
PBar = CreateProgBar(0, 40, 100, 10, window)
CreateButton("Update", 0, 0, 100, 30, window)

Repeat
   If GetKey() = 27 Then End
   event = WaitEvent()
   Select event
      Case $803
         End
      Case $401
         v# = v# + 0.05
         If v#>1 Then v# = 0
         UpdateProgBar PBar, v#
   End Select
Forever
