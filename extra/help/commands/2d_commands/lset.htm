Hilfe

LSet

Aufruf

neu$ = LSet$ (text$, anzahl)

Parameter

text$ beliebiger Text, der geändert werden soll
anzahl neue Zeichenanzahl


Rückgabewert

Neuer Text mit übergebener Zeichenanzahl


Beschreibung

Diese Stringfunktion ändert die Zeichenanzahl eines Textes. Hat ein Text zu wenig Zeichen, so werden einfach hinter dem Text einige Leerzeichen hinzugefügt - somit hat ein Text dann genau die voreingestellte Zeichenanzahl. Ist ein Text dagegen zu lang, so wird der linksbündig zurechtgeschnitten. Beachte, dass der Text immer linksbündig zurückgeliefert wird!


Beispiel

Dieses Beispiel manipuliert die Leerzeichen eines Strings:

txt$ = "Größtenteils harmlos."

;Leerzeichen hinten anfügen, bis String 30 Zeichen hat
txt$ = LSet(txt$,30)
Print "_" + txt$ + "_"

;Leerzeichen vorne anfügen, bis String 50 Zeichen hat (also 20 Leerzeichen)
txt$ = RSet(txt$,50)
Print "_" + txt$ + "_"

;alle Leerzeichen mit einem Befehl wieder entfernen
txt$ = Trim(txt$)
Print "_" + txt$ + "_"
