Hilfe

HidePointer

Aufruf

HidePointer [canvas]

Parameter

canvas Nur für BlitzPlus: Handle eines Canvas. Der Zeiger wird dann beim Eintreten in das Canvas versteckt.


Rückgabewert

-


Beschreibung

Wird ein Programm im Fenstermodus gestartet, so erscheint immer der Windows-Mauszeiger, auch wenn man einen eigenen Mauszeiger in sein Programm eingebaut hat. Mit HidePointer kann der Windows-Mauszeiger ausgeschaltet werden. Ist der Zeiger über dem Programmfenster, so wird er automatisch ausgeblendet, sonst erscheint er wieder.


Beispiel

Demonstriert die Funktion von HidePointer und ShowPointer:

Graphics 640, 480, 32, 2

SetBuffer BackBuffer()

HidePointer

Text 10, 10, "Kein Mauszeiger vorhanden!"
Flip

WaitKey
FlushKeys

ShowPointer

Cls
Text 10, 10, "Zeiger wieder da!"
Flip

WaitKey

EndGraphics
End
