Hilfe

StartNetGame

Aufruf

Wert = StartNetGame ()

Parameter

-


Rückgabewert

0 = Netzwerkspiel nicht gestartet
1 = Netzwerkspiel gestartet
2 = Netzwerkspiel gestartet (dieser PC ist der Host)


Beschreibung

StartNetGame startet ein Netzwerkspiel. Dazu wird ein Windows-Fenster geöffnet, wo man die Verbindung sowie ein Spiel auswählen kann.
Dieser Befehl liefert Null zurück, wenn eine Verbindung nicht hergestellt werden konnte. Bei 1 hat alles geklappt und der Spieler ist zum Spiel beigetreten. Bei 2 hostet der Rechner das Spiel.


HostNetGame, JoinNetGame oder StartNetGame sollte vor allen anderen Netzwerk-Befehlen ausgeführt werden, da die anderen Befehle ohne eine Verbindung nicht funktionieren.

 

Dieser Befehl hat den Nachteil, dass ein neues Fenster erscheint und BlitzBasic-Programmfenster minimiert wird. Dafür braucht man sich um nichts zu kümmern.
 



Diese DialogBox erscheint nach der Ausführung.


Beispiel

Standardbeispiel:

;Startet ein Spiel und wertet den Rückgabewert aus:

newGame = StartNetGame()
If newGame = 0 Then
   Print "Keine Verbindung hergestellt"
ElseIf newGame = 1 Then
   Print "Verbindung hergestellt"
ElseIf newGame = 2 Then
   Print "Ein neues Spiel wurde erstellt"
EndIf
