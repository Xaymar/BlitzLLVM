Hilfe

TerrainHeight

Aufruf

Height# = TerrainHeight# (Terrain, X, Z)

Parameter

Terrain Identität eines Terrains
X X-Koordinate auf dem Terrain
Z Z-Koordinate auf dem Terrain


Rückgabewert

Der Höhenpunkt auf einer Koordinate des Terrains wird zurückgeliefert (Werte nur von 0 bis 1).


Beschreibung

Die Funktion TerrainHeight liefert die Höhe eines Gitterpunktes auf der Koordinate X|Z des ausgewählten Terrains. Dabei kann nur ein Wert von 0 bis 1 zurückgeliefert werden. Mit ModifyTerrain kann dieser Punkt dann geändert werden. Die Funktion TerrainY ist meistens sinnvoller.


Beispiel

Standardbeispiel:

Function setze_obj_auf_terrain(entity, terrain, offset#)
   temp_x# = EntityX(entity)
   temp_z# = EntityZ(entity)
   hoehe# = TerrainHeight#(terrain, temp_x#, temp_z#) + offset
   TranslateEntity entity, temp_x#, hoehe#, temp_z#
End Function
