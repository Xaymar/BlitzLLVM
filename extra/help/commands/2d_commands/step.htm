Hilfe

Step

Aufruf

For variable = start To ende [Step stufe]

Parameter

variable Beliebiger Variablenname (für einfache Zählungen wird meistens i genommen)
start Abfangswert für variable
ende Endwert für variable
stufe Stufensprung für die Zählung (Optional/Standard=1)


Rückgabewert

-


Beschreibung

Dieser Befehl kann nur zusammen mit For Next verwendet werden. Es definiert den Stufensprung bei der Zählung. Normalerweise ist der Stufensprung gleich 1. In diesem Fall kann Step ganz weggelassen werden. Wird ein anderer Wert benötigt, so sollte unbedingt Step verwendet werden.

Mit diesem Befehl ist auch ein Rückwärtszählen möglich. Dafür muss ein negativer Wert übergeben werden. Der Startwert in der For Schleife muss höher sein als der Endwert.
 



Beispiel

Dieses Beispiel schreibt 4 mal den Text "Hello World":

For i = 1 To 20 Step 4

   Print "Hello World"
