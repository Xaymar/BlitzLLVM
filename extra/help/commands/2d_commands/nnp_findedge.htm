Hilfe

NNP_FindEdge

Aufruf

NNP_FindEdge.TEdge( X, Y, Distance#, Entity.TEntity )

Parameter

X X - Position des Punktes
Y Y - Position des Punktes
Distance# Maximaler Abstand, den die Edge vom Punkt haben kann, um noch erkannt zu werden
Entity.TEntity Das Entity, das durchsucht werden soll


Rückgabewert

Falls eine Edge gefunden wird, die die Bedingungen erfüllt, wird sie zurückgeliefert, ansonsten Null


Beschreibung

Dieser Befehl sucht nach der Edge, die am nächsten beim angegebenen Punkt liegt, deren Abstand zum Punkt aber nicht grösser ist als die angegebene Grenze. Dabei wird im übergebenen Entity gesucht.
Falls keine entsprechende Edge gefunden wurde, liefert die Version Null zurück.

Wird beim letzten Parameter Null angegeben, so werden alle Entities durchsucht.
