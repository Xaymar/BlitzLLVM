Es wird ein Wert zurückgeliefert, der vorher mit SeedRnd gesetzt wurde.


Beschreibung

Die Funktion RndSeed liefert einen Wert zurück, der vorher mit SeedRnd gesetzt wurde. Dieser Wert ist für weitere Zufallswerte entscheidend. Man stellt mit diesem Wert einen Zufallsmuster ein. Normalerweise kann man diesen gesetzten Wert manuell speichern und dann abfragen - oder halt diese Funktion benutzen.


Beispiel

Hier wird nach einem Start ein Zufallmuster bestimmt, dann erneut mit Zufallszahl. Dieser Wert wird dann ausgegeben:

SeedRnd MilliSecs ()

SeedRnd Rand (0,10000)
