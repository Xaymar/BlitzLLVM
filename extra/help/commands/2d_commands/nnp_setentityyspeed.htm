Hilfe

NNP_SetEntityYSpeed

Aufruf

NNP_SetEntityYSpeed( Entity.TEntity, VY# )

Parameter

Entity.TEntity Entity, dessen Geschwindigkeit verändert werden soll
VY# Neue Geschwindigkeit auf der Y - Achse


Rückgabewert

-


Beschreibung

Dieser Befehl setzt die Y - Geschwindigkeit aller Vertices vom angegebenen Entity auf einen neuen Wert.

Dieser Befehl ist gut dafür geeignet, ein Objekt anzuhalten oder seine Rotation zu stoppen.
