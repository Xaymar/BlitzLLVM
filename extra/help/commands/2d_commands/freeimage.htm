Aufruf

FreeImage bild

Parameter

bild Identität des Bildes (z.B. mit LoadImage ermittelt)


Rückgabewert

-


Beschreibung

Diese Anweisung entfernt ein vorher mit LoadImage geladenes Bild aus dem Speicher. Dadurch wird mehr Speicher frei. Dies sollte möglichst angewendet werden, um den Speicher zu schonen - besonders bei älteren Rechnern wird es da kritisch.

Das manuelle Löschen eines Bildes muss nicht angewendet werden. BlitzBasic macht es automatisch, wenn das Programm beendet wird. Allerdings kann man so während des Spiels unnötigen Speicher freigeben.
 


Beispiel

Standardbeispiel:

Graphics 640, 480
Bild = LoadImage("Bild.bmp")
DrawBlock Bild, 0, 0
WaitKey()
FreeImage Bild
End
