Hilfe

CreateLabel

Aufruf

label = CreateLabel (text$, x, y, breite, höhe, gruppe [,style] )

Parameter

text Text, der ausgegeben werden soll
x Koordinate X
y Koordinate Y
breite Breite des Label-Objekts
höhe Höhe des Label-Objekts
gruppe Identität einer Gruppe
style 0=normal (Standard)
1=schwarzer Rahmen
3=3D-Rahmen
+65536=Objekt fixieren


Rückgabewert

Identität des Label-Objekts wird zurückgeliefert


Beschreibung

Label ist ein Objekt zum Anzeigen von Text - es ist nicht interaktiv und liefert keine Events zurück. Sollte der Text zu lang sein, dann wird der umgebrochen. Mit Chr$(13) kann man einen manuellen Zeilenumbruch erzwingen.


Beispiel

Standardbeispiel:

window=CreateWindow("Window",0,0,200,200,0,1)
label=CreateLabel("Das ist ein"+Chr$(13)+Chr$(13)+"TEXT",10,10,200,200,window)
WaitKey()
End
