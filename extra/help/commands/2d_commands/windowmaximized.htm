Hilfe

WindowMaximized

Aufruf

wert = WindowMaximized (fenster)

Parameter

fenster Identität eines Fensters


Rückgabewert

0 = Fenster ist nicht Maximiert
1 = Fenster ist Maximiert


Beschreibung

Die Funktion WindowMaximized ermittelt, ob ein Fenster maximiert ist. Ein maximiertes Fenster hat maximale Größe (entspricht ca. Desktopgröße).


Beispiel

Standardbeispiel:

;Dieses Beispiel erzeugt ein Fenster, welches seine Titelzeile entsprechend seinem Status (minimiert, maximiert, normal) ändert (achte am besten auf die Taskbar).

window=CreateWindow("Fenster normal",0,20,400,300,0,3)

Repeat
   If GetKey()=27 Then End
   If WaitEvent()=$803 Then End
   If WindowMinimized(window) Then
      SetGadgetText(window,"Fenster minimiert")
   ElseIf WindowMaximized(window) Then
      SetGadgetText(window,"Fenster maximiert")
   Else
      SetGadgetText(window,"Fenster normal")
   EndIf
Forever
