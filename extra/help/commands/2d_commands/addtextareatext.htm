Hilfe

AddTextAreaText

Aufruf

AddTextAreaText textarea,text$

Parameter

textarea Identität eines Textarea-Objekts
text Text, der eingefügt werden soll


Rückgabewert

-


Beschreibung

Die Anweisung AddTextAreaText fügt Text immer ganz hinten in ein Textarea-Objekt ein. Textarea ist ein RichTextBox-Objekt - somit lässt sich Schriftart oder Schriftfarbe einstellen (siehe dazu SetTextAreaFont, SetTextAreaColor). Mit TextAreaText kann kompletter Text als String wieder ausgelesen werden (ohne Formatierungen!)

Zeilenumbruch lässt sich auch sehr einfach mit Chr$(13)+Chr$(10) einfügen!
 




Beispiel

Erstellt ein Textarea-Objekt und fügt zwei Zeilen Text mit einem Befehl ein:

window = CreateWindow("Window", 50, 50, 300, 300, 0)
textarea = CreateTextArea(10, 10, 270, 200, window)
AddTextAreaText textarea, "Zeile1" + Chr$(13) + Chr$(10) + "Zeile2"

Repeat
   If GetKey() = 27 Then End
   If WaitEvent() = $803 Then End
Forever
