Hilfe

CreateDir

Aufruf

CreateDir Pfad$

Parameter

Pfad Ein Ordner, der erstellt werden soll. Am Ende ohne "\"


Rückgabewert

-


Beschreibung

Erstellt ein ganz neues Verzeichnis. Benutze FILETYPE, um festzustellen, ob ein Verzeichnis bereits existiert.

Dieser Befehl liefert keine Werte - man kann also nicht direkt erfahren, ob ein Verzeichnis erstellt wurde oder nicht. Benutze dafür FILETYPE. Ein Verzeichnis kann nicht auf einem schreibgeschützten Medium erstellt werden.
 


Beispiel

Erstellt und löscht einen Ordner

Ordner$="C:\MeinOrdner"
CreateDir Ordner$
Print "Ordner erstellt!"
ChangeDir ordner$
Print CurrentDir$()
ChangeDir "c:\"
DeleteDir Ordner$
Print "Ordner gelöscht!"
Print CurrentDir$()
