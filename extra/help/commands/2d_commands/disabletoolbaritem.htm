Hilfe

DisableToolBarItem

Aufruf

DisableToolBarItem toolbar, index

Parameter

toolbar Identität eines Toolbar-Objekts
index Indexnummer des Symbols (ab -1)


Rückgabewert

-


Beschreibung



Die Anweisung DisableToolBarItem schaltet ein Symbol in der Toolbar aus. Es erscheint danach grau und reagiert nicht mehr auf Eingaben. Events werden auch nicht mehr zurückgeliefert. Mit EnableToolBarItem kann es wieder eingeschaltet werden.


Beispiel

Erstellt eine Toolbar und schaltet das dritte Symbol aus:

img = CreateImage(96, 32)
SetBuffer ImageBuffer(img, 0)
Color 255, 0, 0
Rect 1, 1, 30, 30, 1
Color 255, 255, 0
Rect 33, 1, 30, 30, 1
Color 0, 255, 0
Rect 65, 1, 30, 30, 1
SaveImage img, "C:\bild.tmp"
FreeImage img

window = CreateWindow("Window", 0, 0, 300, 300, 0, 1)
toolbar = CreateToolBar("c:\bild.tmp", 0, 0, 96, 32, window)
DisableToolBarItem toolbar, 1

Repeat
   If GetKey() = 27 Then End
   nr = WaitEvent()
   If nr = $803 Then DeleteFile "c:\bild.tmp" : End
   If nr = $401 And EventSource() = toolbar Then
      Notify "Symbol=" + EventData()
   EndIf
Forever
