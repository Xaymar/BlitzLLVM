Hilfe

WaitMouse

Aufruf

taste = WaitMouse()

Parameter

-


Rückgabewert

Die Maustaste, welche betätigt wurde.


Beschreibung

Diese Funktion stoppt das ganze Programm und wartet so lange, bis eine Maustaste gedrückt wird.
Um während der Wartezeit Grafikausgaben oder ähnliches machen zu können. Sollte man deshalb auf eine Alternative mit GetMouse ausweichen.

Diese Funktion ist ein Alias für MouseWait.
 


Zusatzinformation

Das Scrollrad wird als dritte Taste interpretiert. Mit den Funktionen MouseZ und MouseZSpeed kann man herausfinden, ob und wie das Scrollrad gedreht wurde.
 


Beispiel

Verschiebt die Maus - demonstriert außerdem die Funktion von MouseWait/WaitMouse:

Graphics 640, 480, 32, 2

SetBuffer BackBuffer()

Text 10, 10, "Wenn du klickst, wird die Maus verschoben!"
Flip

WaitMouse
FlushMouse

MoveMouse 200, 150

Cls
Text 10, 10, "Toll was?"
Flip

MouseWait

EndGraphics
End
