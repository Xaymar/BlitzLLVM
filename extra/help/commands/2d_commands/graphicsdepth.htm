Hilfe

GraphicsDepth

Aufruf

tiefe = GraphicsDepth ()

Parameter

-


Rückgabewert

Farbtiefe in Bit.
16 Bit entsprechen 65536 Farben
24 Bit entsprechen 16,7 Mio. Farben
32 Bit entsprechen 16,7 Mio. Farben (kein Schreibfehler!)


Beschreibung

Diese Funktion ermittelt die aktuelle Farbtiefe. Wird bei Graphics der Wert für Farbtiefe nicht angegeben, so kann man über diese Funktion die gesetzte Farbtiefe ermitteln. Für spätere Grafikausgabe hat dieser Wert keine Bedeutung. Man kann höchstens einen Hinweis ausgeben, dass die Farbtiefe zu gering ist.


Beispiel

Dieses Beispiel öffnet ein Grafikfenster und ermittelt die wichtigsten Werte:

Graphics 640,480,16

SetBuffer FrontBuffer ()

Print "Bildschirmbreite: " + GraphicsWidth ()

Print "Bildschirmhöhe: " + GraphicsHeight ()

Print "Farbtiefe: " + GraphicsDepth ()

Print "Bufferidentität: " + GraphicsBuffer ()
