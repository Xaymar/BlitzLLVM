Hilfe

NewCL

Aufruf

HANDLE.CL = NewCL(handle, x_start#, y_start#, x_end#, y_end#)

Parameter

handle Identität einer Textur (siehe dazu Line3D)
x_start# X-Startkoordinate der Kollisionslinie
y_start# Y-Startkoordinate der Kollisionslinie
x_end# X-Endkoordinate der Kollisionslinie
y_end# Y-Endkoordinate der Kollisionslinie


Rückgabewert

HANDLE.VK = Die Identität des erstellten CL


Beschreibung

Erstellt eine neue CL (CollisionsLine). Eine CL ist eine Kollisionsfläche auf der erstellte KP kollidieren können. Die Kollisionsfläche ist immer vom Vektor aus gesehen links. Der Vektor geht von x_start / y_start nach x_end / y_end. Wird zum Beispiel die Kollisionslinie von links nach rechts gezeichnet, so kann man von Oben drauf rum laufen.
