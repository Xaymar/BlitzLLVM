Hilfe

NNP_CopyEntity

Aufruf

NNP_CopyEntity.TEntity( Entity.TEntity )

Parameter

Entity.TEntity Das Entity, das kopiert werden soll


Rückgabewert

Das Entity, das kopiert wurde.


Beschreibung

Diese Funktion kopiert das angegebene Entity mit all seinen Eigenschaften und liefert die Kopie zurück.

Die Kollisionsgruppe des Entitys wird beim Kopieren neu verteilt - soll die Kopie in der selben Kollisionsgruppe sein, so muss man dies manuell nachkorrigieren.
