Hilfe

HostIP

Aufruf

ip = HostIP (index)

Parameter

index Index des Hostes (Startwert ist 1)


Rückgabewert

Integer-IP-Adresse eines Hostes


Beschreibung

Diese Funktion ermittelt die IP-Adresse eines bestimmten Hostes. Der Startwert für den Index ist 1. Der Endindex entspricht dem Wert aus der Funktion CountHostIPs.

Mit dem Befehl DottedIP kann man die korrekte IP-Nummer aus dem Integerwert ermitteln.


Beispiel

Dieses Beispiel gibt die IP-Adresse des Rechners aus:

n = CountHostIPs("")
ip = HostIP(1) ;internal ID
ipaddress$ = DottedIP$(ip)

Print "Dotted IP Test"
Print "=============="
Print ""
Print "Internal Host IP ID:" + ip
Print "Dotted IP Address:" + ipaddress$
Print ""
Print "Press any key to continue"

WaitKey()
End
