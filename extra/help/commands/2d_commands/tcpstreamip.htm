Hilfe

TCPStreamIP

Aufruf

IP = TCPStreamIP (Stream)

Parameter

Stream Identität des TCP/IP-Streams


Rückgabewert

Es wird eine Integer-IP-Adresse zurückgeliefert. Benutze DottedIP, um daraus die normale IP-Adresse zu ermitteln.


Beschreibung

Diese Funktion ermittelt die IP-Adresse eines TCP/IP-Streams. Zurückgeliefert wird ein Integerwert. Mit DottedIP kann es in eine normale IP-Adresse umgewandelt werden. Die IP-Adresse ist immer von der Client-Maschine.


Beispiel

Standardbeispiel:

stream = OpenTCPStream("http://www.blitzbasic.ch",80)
stream_ip = TCPStreamIP( stream )
dotted_ip$ = DottedIP( stream_ip )
stream_port = TCPStreamPort( stream )

Print stream_ip
Print dotted_ip
Print stream_port

WaitKey()
CloseTCPStream(stream)
