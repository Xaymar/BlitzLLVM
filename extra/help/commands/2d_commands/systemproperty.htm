Hilfe

SystemProperty

Aufruf

text$ = SystemProperty$ (name$)

Parameter

name$ Der Name der Information die man erhalten will. Zur Auswahl stehen folgende String-Konstanten:

"APPDIR" - Liefert Name des BlitzBasic-Ordners
"OS" - Liefert Name des Betriebssystems (nicht unter Vista)
"SYSTEMDIR" - Liefert Name des System-Ordners
"TEMPDIR" - Liefert Name des Temp-Ordners
"WINDOWSDIR" - Liefert Name des Windows-Ordners

Weitere Parameter sind: Direct3D7, Direct3DDevice7, DirectDraw7, DirectInput7, AppHWND und AppHINSTANCE


Rückgabewert

Liefert einen String zurück, der dann vorher ausgewählte Informationen enthält.


Beschreibung

Diese Funktion liefert bestimmte Systeminformationen zurück. Zur Auswahl stehen noch nicht sehr viele Möglichkeiten. Vorteil: Der Entwickler der Programmiersprache BlitzBasic kann es problemlos erweitern.


Beispiel

Standardbeispiel:

Print "BlitzBasic-Ordner: " +SystemProperty$ ("APPDIR")
Print "System-Ordner: " +SystemProperty$ ("SYSTEMDIR")
Print "Temp-Ordner: " +SystemProperty$ ("TEMPDIR")
Print "Windows-Ordner: " +SystemProperty$ ("WINDOWSDIR")
Print "Betriebssystem: " +SystemProperty$ ("OS")
