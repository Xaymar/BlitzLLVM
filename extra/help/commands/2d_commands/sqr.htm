Hilfe

Sqr

Aufruf

wert# = Sqr(zahl#)

Parameter

zahl Beliebige Zahl


Rückgabewert

Liefert die Wurzel der eingegebenen Zahl


Beschreibung

Diese mathematische Funktion zieht die Quadratwurzel aus einer Zahl. Wird das Ergebnis mit sich selbst multipliziert, so erhält man wieder die alte Zahl.

Die Quadratwurzel kann auch nach dieser Formel berechnet werden:
Wert = Zahl ^ 0.5

Mit dieser Funktion kann aber keine Kubikwurzel berechnet werden. Dies kann mit der Zeile geschehen:
Wert = Zahl ^ 0.333333
