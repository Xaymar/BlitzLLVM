Hilfe

Windowed3D

Aufruf

wert% = Windowed3D ()

Parameter

-


Rückgabewert

Wenn Fenstermodus unterstützt wird, dann wird 1 zurückgeliefert, sonst aber 0.


Beschreibung

Die Funktion Windowed3D prüft, ob die 3D-Grafikausgabe in einem Fenster und nicht im Vollbildmodus erfolgen kann.

Einige Grafikkarten haben große Probleme damit, die 3D-Grafik in einem Fenster anzuzeigen. Darum sollte man es vorher mit dieser Funktion prüfen. Im Vollbildmodus gibt es dagegen fast nie Probleme.

Wenn Fenstermodus unterstützt wird, dann wird 1 zurückgeliefert. Ansonsten wird nur 0 zurückgeliefert.


Beispiel

Standardbeispiel:

If Windowed3D()
   Graphics3D 640, 480, 0, 2
   Print "Fenstermodus!"
Else
   Graphics3D 640, 480, 0, 1
   Print "Nur Vollbildmodus!"
EndIf
WaitKey()
End
