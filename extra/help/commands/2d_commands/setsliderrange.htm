Hilfe

SetSliderRange

Aufruf

SetSliderRange slider, sichtbar, total

Parameter

slider Identität eines Slider-Objekts
sichtbar Sichtbare Breite/Höhe
total Gesamte Breite/Höhe


Rückgabewert

-


Beschreibung

Die Anweisung SetSliderRange definiert den Bewegungsbereich eines Slider Objekts.



Der Parameter "Sichtbar" gibt die sichtbare Breite/Höhe an (z.B. sichtbare Einträge oder sichtbare Größe eines Bildes). Der Parameter "Total" gibt die Gesamtgröße an (z.B. Anzahl der Einträge oder Größe eines Bildes).

Mit SetSliderValue kann die Position eingestellt werden. Mit SliderValue kann aktuelle Position ausgelesen werden.


Beispiel

Ein Fenster mit drei Slider-Objekten. Der grosse Slider dient als Testslider und die unteren 2 als Kontrolle (visible,range):

window = CreateWindow ("Fenster",0,20,400,300,0,3)
slider = CreateSlider (0,0,200,20,window)
visslider = CreateSlider (0,50,100,10,window)
rangeslider = CreateSlider (0,70,100,10,window)

SetSliderRange (slider,0,100 )
SetSliderRange (visslider,0,100 )
SetSliderRange (rangeslider,0,100 )
SetSliderValue (rangeslider,100 )

Repeat
   If GetKey () = 27 Then End
   Select WaitEvent ()
   Case $803
   End
   Case $401
   SetSliderRange (slider, SliderValue (visslider), SliderValue (rangeslider) )
   SetGadgetText (window,"Sliderposition: "+SliderValue(slider))
   End Select
Forever
