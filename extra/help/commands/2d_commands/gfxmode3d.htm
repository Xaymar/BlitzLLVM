Hilfe

GfxMode3D

Aufruf

wert% = GfxMode3D (modus%)

Parameter

modus% Bildschirmmodus (ab 1). Die maximale Anzahl der Bildschirmmodi kann mit CountGfxModes ermittelt werden.


Rückgabewert

0=Der Grafikmodus ist nicht für 3D geeignet
1=Der Grafikmodus ist für 3D geeignet


Beschreibung

Die Funktion GfxMode3D prüft, ob ein Grafikmodus für 3D geeignet ist. Wenn es 3D-fähig ist, dann wird 1, andernfalls wird nur 0 zurückgeliefert.

Benutze CountGfxModes, um die Anzahl der unterstützten Auflösungen festzustellen.


Zusatzinformation

Es könnte sein, dass zwar die Grafikkarte diesen Modus unterstützt, der Monitor aber nicht. So können manche Monitore große Auflösungen wie 1600x1200 nicht darstellen.
 


Beispiel

Standardbeispiel:

For a = 1 To CountGfxModes()
   If GfxMode3D(a) = 1 Then
      Print "Modus " + a + " [3D-kompatibel]"
   Else
      Print "Modus " + a + " nicht [3D-kompatibel]"
   EndIf
Next
