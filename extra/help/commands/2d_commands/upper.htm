Hilfe

Upper

Aufruf

neu$ = Upper$ (text$)

Parameter

text$ beliebiger Text, der umgewandelt werden soll


Rückgabewert

Ein String mit umgewandelten Text.


Beschreibung

Diese Stringfunktion wandelt alle Buchstaben des angegebenen Textes in Großbuchstaben um. Die Lower-Funktion funktioniert genau umgekehrt.

Leider werden die deutschen Umlaute, wie bei vielen anderen Programmiersprachen, nicht umgewandelt - hier muss man selbst programmieren. Benutze dazu den Befehl Replace.
 


Beispiel

Hier wird mit Hilfe von Lower, Upper und Replace ein Text manipuliert:

txt$ = "dAs IsT eIn BeIsPiElTeXt."

Print "alles klein: " + Lower$(txt$)
Print "alles groß: " + Upper$(txt$)
Print "ohne Leerzeichen: " + Replace$(txt$," ","")
