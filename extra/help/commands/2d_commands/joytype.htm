Hilfe

JoyType

Aufruf

typ = JoyType( [port] )

Parameter

port Die Nummer des Joysticks (ab 0)


Rückgabewert

0 - kein Joystick vorhanden
1 - digitaler Joystick
2 - analoger Joystick


Beschreibung

Diese Funktion ermittelt die Art des Joysticks, der am Computer angeschlossen ist. Es gibt zwei Typen: digital und analog.
Ein digitaler Joystick kann nur sagen, dass in eine Richtung gelenkt wird, bei einem analogen Joystick kann zusätzlich die Stärke ermittelt werden. So ist es etwa möglich nur 50% nach vorne zu drücken und dadurch die Spielfigur langsamer laufen zu lassen.


Beispiel

Standardbeispiel:

Select JoyType()
   Case 0
      Print "Sorry, kein Joystick vorhanden"
   Case 1
      Print "Digitaler Joystick vorhanden"
   Case 2
      Print "Analoger Joystick vorhanden"
End Select
