Hilfe

CountGfxModes

Aufruf

anzahl = CountGfxModes ()

Parameter

-


Rückgabewert

Anzahl der unterstützten Grafikmodi


Beschreibung

Ermittelt die Anzahl der unterstützten Grafikmodi von der Grafikkarte. Benutze GfxModeWidth, GfxModeHeight und GfxModeDepth, um weitere Informationen über einen Grafikmodus zu ermitteln. Mit Graphics kann man einen Grafikbildschirm öffnen.

Tipp: Erstelle ein Menü, wo der Spieler selbst eine Auflösung auswählen kann.
 


Beispiel

Dieses Programm zeigt die Anzahl der Grafiktreiber und alle unterstützten Auflösungen des zur Zeit aktiven Treibers:

anzahl = CountGfxDrivers ()
Print "Anzahl der Treiber: "+Anzahl

anz = CountGfxModes ()
Print "Anzahl der Bildschirmmodi: "+anz

For i = 1 to anz
   Print "Modus " + i + ": "
   Print "Breite = " + GfxModeWidth (i)
   Print "Höhe = " + GfxModeHeight (i)
   Print "Tiefe = " + GfxModeDepth (i)
   Print
Next
