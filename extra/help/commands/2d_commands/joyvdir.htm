Hilfe

JoyVDir

Aufruf

v = JoyVDir( [port] )

Parameter

port Die Nummer des Joysticks (ab 0)


Rückgabewert

Gibt die V-Koordinate (-1, 0, 1) zurück, oder -1 wenn die Funktion nicht unterstützt wird.


Beschreibung

Diese Funktion ermittelt die V-Koordinate des Joysticks. Der Wert ist dabei -1, 0 oder 1. Zusätzlich gibt es noch die Funktion JoyV. Damit kann man eine Richtung feiner ablesen (Kommawerte zwischen -1 und 1).


Zusatzinformationen

Bevor du diese Funktion nutzt solltest du mittels JoyType prüfen, ob überhaupt ein Joystick angeschlossen ist.
Du solltest auch immer an eine alternative Tastatur/Maus-Steuerung denken.
 

Achtung! Nicht jeder Joystick unterstützt diese Funktion.
 


Beispiel

Joystick Abfragen

Graphics 400,300,0,2
SetBuffer BackBuffer()
While Not KeyHit(1)
   Cls
   Text 0, 0, "Hat:" + JoyHat()
   Text 0, 0, "Pitch:" + JoyPitch()
   Text 0, 20, "Yaw:" + JoyYaw()
   Text 0, 40, "Roll:" + JoyRoll()
   Text 200, 0, "U:" + JoyU()
   Text 200, 20, "V:" + JoyV()
   Text 200, 40, "X:" + JoyX()
   Text 200, 60, "Y:" + JoyY()
   Text 200, 80, "Z:" + JoyZ()
   Flip
Wend
End
