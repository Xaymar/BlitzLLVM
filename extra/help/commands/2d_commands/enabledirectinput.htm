Hilfe

EnableDirectInput

Aufruf

EnableDirectInput wert

Parameter

wert 0 - DX Input deaktiviert (Standard)
1 - DX Input aktiviert


Rückgabewert

-


Beschreibung

Die Anweisung EnableDirectInput schaltet DX Input ein oder aus. Seit einiger Zeit wurden alle Inputbefehle von DX Input auf Standard Input umgestellt. Dadurch ist es minimal langsamer als vorher. Jedoch gab es einige Probleme mit DX Input.


Zusatzinformation

Dies ist ein undokumentierter Befehl. Sollte dieser Befehl wieder offiziell entfernt werden, wären Programme zu allen zukünftigen Updates nicht mehr kompatibel und müssten umgeschrieben werden. Die Anwendung ist daher auf eigenes Risiko.
 


Beispiel

Schaltet DX-Input ein. Ermittelt danach Zustand:

EnableDirectInput 1

Print DirectInputEnabled ()

WaitKey
