Hilfe

FreeTimer

Aufruf

FreeTimer timer

Parameter

timer Identität des Timers (ermittelt mit CreateTimer)


Rückgabewert

-


Beschreibung

Diese Anweisung entfernt einen Timer, der mit CreateTimer definiert wurde. Dies sollte dann geschehen, wenn ein Timer nicht mehr länger gebraucht wird.

Das manuelle Löschen eines Timers muss nicht angewendet werden. BlitzBasic macht es automatisch, wenn das Programm beendet wird.
 


Beispiel

Das erzeugen, abfragen und löschen eines Timers. In diesem Fall wird der Bildschirm genau 60 mal pro Sekunde gezeichnet:

frameTimer = CreateTimer (60)
Graphics 640, 480

While Not KeyHit (1)

   CLS
   Text 0, 0 ,"Dies ist ein Timer Test"
   WaitTimer (frameTimer)
   Flip 0

Wend

FreeTimer frameTimer
End
