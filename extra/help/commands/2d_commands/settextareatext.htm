Hilfe

SetTextAreaText

Aufruf

SetTextAreaText textarea, text$ [,pos] [,länge] [,einheit]

Parameter

textarea Identität eines Textarea-Objekts
text Neuer Text, der eingefügt werden soll
pos Einfügeposition (Zeichen bzw. Zeilen)
länge Überschreiblänge (Zeichen bzw. Zeilen)
einheit 1=Einheit in Zeichen (Standard)
2=Einheit in Zeilen


Rückgabewert

-


Beschreibung

Die Anweisung SetTextAreaText fügt einen neuen Text in Textarea-Objekt ein. Position und Überschreiblänge kann beliebig bestimmt werden. Einheit ist entweder in Zeichen oder in Zeilen.

Mit AddTextAreaText kann Text immer nur hinzugefügt werden. Mit SetGadgetText kann kompletter Text ersetzt werden.
