Hilfe

TFormedZ

Aufruf

z# = TFormedZ# ()

Parameter

-


Rückgabewert

Z-Koordinate wird ausgegeben


Beschreibung

Die Funktion TFormedZ liefert die Z-Koordinate der letzten Berechnung, die mit TFormNormal, TFormPoint oder TFormVector ausgeführt wurde.


Beispiel

Standardbeispiel:

Graphics3D 640, 480, 0, 2
SetBuffer BackBuffer()
camera = CreateCamera()
light = CreateLight(1)
RotateEntity light, 90, 0, 0

cube = CreateCube()
EntityColor cube, 100, 100, 255
PositionEntity cube, 0, 0, 5

cube2 = CreateCube()
EntityColor cube2, 100, 100, 255
PositionEntity cube2, 5, 2, 10

While Not KeyDown(1)
   TurnEntity cube, 1, 1, 1
   TurnEntity cube2, - 1, - 1, - 1
   RenderWorld
   
   TFormNormal(1, 1, 1, cube, cube2)
   Text 0, 0, "NORMAL:"
   Text 0, 20, "X=" + TFormedX()
   Text 0, 40, "Y=" + TFormedY()
   Text 0, 60, "Z=" + TFormedZ()
   
   TFormPoint(1, 1, 1, cube, cube2)
   Text 0, 100, "POINT:"
   Text 0, 120, "X=" + TFormedX()
   Text 0, 140, "Y=" + TFormedY()
   Text 0, 160, "Z=" + TFormedZ()
   
   TFormVector(1, 1, 1, cube, cube2)
   Text 0, 200, "VECTOR:"
   Text 0, 220, "X=" + TFormedX()
   Text 0, 240, "Y=" + TFormedY()
   Text 0, 260, "Z=" + TFormedZ()
   
   Flip
Wend
End
