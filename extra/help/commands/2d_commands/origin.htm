Hilfe

Origin

Aufruf

Origin x, y

Parameter

x Integerwert der horizontalen Verschiebung des Ursprungs
y Integerwert der vertikalen Verschiebung des Ursprungs


Rückgabewert

-


Beschreibung

Dieser Befehl verschiebt den Bildschirm-Nullpunkt. Normalerweise ist der Nullpunkt immer oben/links. Man kann den aber auch woanders hinsetzen. Dadurch werden alle nachfolgende Grafiken ersetzt eingezeichnet und die manuelle Verschiebung ist nicht mehr notwendig.

Um den Nullpunkt wieder zurückzusetzen kann Origin 0, 0 verwendet werden.
 


Beispiel

Standardbeispiel:

Graphics 640, 480, 0, 1
Origin 200, 200
Oval 0, 0, 20, 20, 1
WaitKey()
End
