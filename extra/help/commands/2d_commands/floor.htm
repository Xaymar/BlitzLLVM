Hilfe

Floor

Aufruf

Wert# = Floor (Zahl#)

Parameter

Zahl beliebige Zahl (Integer oder Float)


Rückgabewert

Abgerundete Zahl, ohne Kommastellen aber als Float.


Beschreibung

Diese Funktion ist zum Abrunden einer Kommazahl gedacht. Es wird also immer eine ganze Zahl (ohne Nachkommastellen) aber als Floatzahl zurückgeliefert. Dabei wird immer die kleinste Zahl ermittelt. Aus einer Zahl wie 2.9 wird 2.0000 und aus -2.1 wird -3.0000 ermittelt.

Die Funktion Ceil funktioniert genau umgekehrt.


Beispiel

Dieses Beispiel liefert eine 1 zurück:

Print Floor(1.9)
