# Performance history

Results of the benchmarks of BlitzLLVM, kept apart from `root`. Made by `benchmarks/history.py`, `benchmarks/history_commits.py` and
`benchmarks/history_page.py` of the repository (`--results` is a checkout of this branch).

* `r*.json`: the full benchmark set for the revisions listed in `revisions.json`.
* `commits/`: the short set for every code state of `root`.
* `Performance-History.md`, `Performance-History-by-Commit.md`: the generated wiki pages.
