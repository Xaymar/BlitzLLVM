# Performance history

Results of the benchmarks of BlitzLLVM, kept apart from `root`. Made by `benchmarks/history.py`, `benchmarks/history_commits.py` and
`benchmarks/history_page.py` of the repository; one folder per machine.

* `<machine>/r00-original.json`: the baseline, the original Blitz3D 1.118.
* `<machine>/tags/`: which version tag (X.Y.Z) has which code state; `<machine>/commits/`: the benchmark results of those code states.
* `<machine>/Performance-History.md`: the generated wiki page (the Wiki workflow publishes it).

Older results (llvmpipe, every commit) were removed on 2026-10-31 and are in the history of this branch.
