# Performance history

Results of the benchmarks of BlitzLLVM, kept apart from `root`. Made by `benchmarks/history.py`, `benchmarks/history_commits.py` and
`benchmarks/history_page.py` of the repository (`--results` is a checkout of this branch, one folder per machine, e.g. `areldir/`).

* `<machine>/r00-original.json`: the baseline, the original Blitz3D 1.118.
* `<machine>/commits/`: the short benchmark set for the code state of a commit; `<machine>/tags/`: which tag has which state.
* `Performance-History.md`, `Performance-History-by-Version.md`: the generated wiki pages.

Older results (llvmpipe, per commit) were removed on 2026-10-31 and are in the history of this branch.
